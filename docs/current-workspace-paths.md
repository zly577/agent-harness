# 当前工作区路径与长期记忆

`/workspace` 是文件工具的虚拟路径。会话绑定的 `Workspace.directory` 决定其真实目录；例如选中 `D:\Projects\demo` 后，`/workspace/a.txt` 实际对应 `D:\Projects\demo\a.txt`。

智能体、文件面板、下载接口和命令后端使用同一会话工作区。默认会话仍使用该用户的默认目录，显式选择目录的会话使用所选目录，不静默回退。

## 修复内容

- 统一 backend 根目录、`Agent.md` 初始化及 `memory` 加载路径。
- 当前目录的 `Agent.md` 不存在时，首次正常对话创建种子文件；已有文件不覆盖。不复制默认目录中的私人记忆到其他项目。
- 历史读取不创建 `Agent.md`；旧 checkpoint 的空记忆缓存会在正常运行时补齐。
- 主智能体和子智能体的提示词明确真实目录与虚拟路径的对应关系。
- 完全访问模式的 execute 使用当前真实目录，命令采用相对路径或真实路径；沙箱模式仍使用容器 `/workspace`。
- 工具参数详情保留原始虚拟参数，并展示对应真实位置。
- 已选工作区被删除、归属不符或目录不可访问时，明确报错，不创建其他默认目录。

## 验证方式

重启后端并刷新前端，选择一个带有独特文件的工作区，发起新会话让智能体读取该文件。工具可仍显示 `/workspace/文件名`，展开操作详情应显示所选目录的真实路径。
检查该目录的 `Agent.md` 能正常读取，默认用户目录内原有记忆不应被覆盖。

## Agent.md 何时生效

`Agent.md` 是工作区记忆：工作区 A 和 B 分别使用各自目录的文件，同一工作区的会话共享它。文件名沿用现有的 `Agent.md`，文件工具路径为 `/workspace/Agent.md`。

| 时机 | 行为 |
| --- | --- |
| 新会话第一次发送消息 | 加载当前工作区最新的 Agent.md，缺失时创建种子文件 |
| 已有会话发送下一条消息 | 检查文件变化，变化时在对话末尾追加一次内部通知，保持前面的记忆基线稳定 |
| 同一轮内多次调用模型、工具 | 保留相同系统记忆基线，直接使用对话及工具结果里的新信息 |
| 本轮通过 remember 修改记忆 | 立即落盘；工具完成后核对实际文件版本，已在本会话工具上下文中的修改不再重复通知，随后的压缩也会合并该修改 |
| 设置页或另一个会话修改记忆 | 当前回答不中途刷新，下一轮接收必要的差异通知；同工作区新会话加载最新全文 |
| 文件工具或 shell 修改记忆，来源无法可靠确认 | 下一轮追加一次变更通知，避免漏掉同时发生的外部修改 |
| 文件被清空或删除 | 下一轮通过通知宣布此前相关条目失效，保留输入前缀 |
| 上下文压缩 | 把最新已观察记忆合并成新基线，从模型视图中去掉已合并通知，原始消息索引保持不变 |
| 仅查看历史记录 | 不创建记忆文件，不执行模型 |

初始记忆保存在 checkpoint 的 `memory_contents` 中，模型每次请求都会收到相同基线。最新已观察版本与通知进度另存于私有会话状态中，重启后继续使用。后端检查是本地文件读取，不产生 `read_file` 工具调用。内容不变时不发送通知；变化时优先发送简短差异，差异更长时发送当前加载范围的替代内容。详细记忆索引只列路径，不因修改时间变化而重复通知。

内部通知会进入模型上下文，但不会当作用户指令加入任务记录，也不会在聊天界面、展示归档或历史搜索中出现。通知带版本并说明删除和替代关系，当前用户指令及核实的事实优先。

这样可减少记忆更新导致的输入前缀变化；实际缓存命中仍取决于模型供应商、其他提示词和消息变化，不保证完整命中。基线及少量通知仍占输入 token，压缩时会有一次上下文重建。超出核心容量的正文和详细记忆继续按需读取。
