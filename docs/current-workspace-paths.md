# 当前工作区路径与长期记忆

`/workspace` 是文件工具的虚拟路径。会话绑定的 `Workspace.directory` 决定其真实目录；例如选中 `D:\Projects\demo` 后，`/workspace/a.txt` 实际对应 `D:\Projects\demo\a.txt`。

智能体、文件面板、下载接口和命令后端使用同一会话工作区。默认会话仍使用该用户的默认目录，显式选择目录的会话使用所选目录，不静默回退。

## 修复内容

- 统一 backend 根目录、`Agent.md` 初始化及 `memory` 加载路径。
- 当前目录的 `Agent.md` 不存在时，首次正常对话创建种子文件；已有文件不覆盖。不复制默认目录中的私人记忆到其他项目。
- 历史读取不创建 `Agent.md`；旧 checkpoint 的空记忆缓存会在正常运行时补齐。
- 主智能体和子智能体的提示词明确真实目录与虚拟路径的对应关系。
- 完全访问模式的 execute 使用当前真实目录，命令采用相对路径或真实路径；沙箱模式仍使用容器 `/workspace`。
- 工具参数详情保留原始虚拟参数，并展示对应真实位置。
- 已选工作区被删除、归属不符或目录不可访问时，明确报错，不创建其他默认目录。

## 验证方式

重启后端并刷新前端，选择一个带有独特文件的工作区，发起新会话让智能体读取该文件。工具可仍显示 `/workspace/文件名`，展开操作详情应显示所选目录的真实路径。
检查该目录的 `Agent.md` 能正常读取，默认用户目录内原有记忆不应被覆盖。
